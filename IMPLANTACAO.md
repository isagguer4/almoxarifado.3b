# Guia de Implementação e Infraestrutura

## Pré-requisitos de Ambiente (Local)
Para rodar este projeto, seu computador deve ter instalado:
- [ ] PHP (Versão 8.2 ou superior);
- [ ] Composer (gerenciador de pacotes do PHP)
- [ ] Filament (Framework para o laravel)
- [ ] NPM
- [ ] Banco de dados MySQL

## Checklist de Instalação
- [ ] Criar a estrutura de base de Dados no Laravel
- [ ] Instalar o Filament
- [ ] Configurar o arquivo de variáveis de ambiente ('.env)
- [ ] Rodas as aplicações do banco de dados ('migrations')
